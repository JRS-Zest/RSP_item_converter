====================================================
  RSPアイテム一括生成.exe  ビルド手順
====================================================
最終更新: 2026-04-26


■ 成果物
  dist\RSPアイテム一括生成.exe  （約11 MB、単一ファイル）
  ・Python ランタイムを内包済み（実行先に Python インストール不要）
  ・Windows 10/11 x64 対応


====================================================
1. このフォルダに必要なファイル
====================================================

以下のファイルがすべて同じフォルダ内にあること:

  RSPアイテム一括生成.py            ← メインスクリプト（GUIエントリポイント）
  複合itemdatからjson抽出.py         ← item.dat 復号＆JSON抽出（EXEに同梱）
  rsp_tooltip_generator.py           ← ツールチップ文字列生成（EXEに同梱）
  render_rsp_items.py                ← アイテム表示用レンダリング（EXEに同梱）
  アイテム表示用HTMLベース.html      ← 出力HTMLのテンプレート（EXEに同梱）
  RSPアイテム一括生成.spec           ← PyInstaller設定ファイル（再ビルド時に使う）


====================================================
2. 事前準備（初回のみ）
====================================================

(1) Python 3.13 以上をインストール（ビルド作業用。実行先には不要）
    https://www.python.org/downloads/
    ※ インストール時に「Add Python to PATH」にチェックを入れること

(2) PyInstaller をインストール
    コマンドプロンプトで実行:

    pip install pyinstaller


====================================================
3. EXEビルド手順
====================================================

(1) コマンドプロンプトを開く

(2) このフォルダへ移動
    cd /d "このフォルダのフルパス"
    例: cd /d "C:\RSPツール\RSPアイテム一括生成"

(3) .spec ファイルを使ってビルド（推奨）
    pyinstaller RSPアイテム一括生成.spec

    ─ または手動で全オプションを指定する場合 ─
    pyinstaller --onefile --windowed ^
      --name "RSPアイテム一括生成" ^
      --add-data "複合itemdatからjson抽出.py;." ^
      --add-data "rsp_tooltip_generator.py;." ^
      --add-data "render_rsp_items.py;." ^
      --add-data "アイテム表示用HTMLベース.html;." ^
      "RSPアイテム一括生成.py"

(4) 完了すると dist\ フォルダに EXE が生成される
    dist\RSPアイテム一括生成.exe


====================================================
4. ビルド時に生成される不要フォルダ（削除可）
====================================================
  build\       ← ビルド中間ファイル（削除可）
  __pycache__\ ← Python キャッシュ（削除可）
  *.spec       ← 設定ファイル（再ビルド用に残しておく）


====================================================
5. EXEの動作概要
====================================================

起動時に以下をレジストリから自動取得:
  HKEY_CURRENT_USER\Software\L&K Logic Korea\Red Stone Portable for Japan

    "Version"  → 出力ファイル名の番号（例: 601 → RSPitem_0601.html）
    (※Update後は一度クライアントEXEを起動しないとレジストリVersion情報が書き換わらないので一度ゲームを起動してVersion情報を更新してから実行しないと旧バージョンのまま生成されるので要注意)

    "path"     → item.dat / textData.dat のデフォルトパス

入力ファイル（GUIで変更可能）:
  ※起動時はレジストリPath情報から自動入力されるが一応変更も可能
  ① item.dat       例: C:\Program Files (x86)\GameON\RED STONE Portable\Data\Scenario\Red Stone\item.dat
  ② textData.dat   例: C:\Program Files (x86)\GameON\RED STONE Portable\Data\textData.dat

出力先（GUIで変更可能）:
  ③ 出力フォルダ   デフォルト: EXE と同じフォルダを初期設定フォルダにしてあるが変更も可能。どこでも可
     → RSPitem_0601.html が生成される

処理パイプライン（全てEXE内部で完結、中間ファイルなし）:
  item.dat (暗号化)
    └─ PacketCrypt 復号
    └─ JSON抽出（426バイト/アイテム固定長）
    └─ ツールチップ生成（textData.dat の文字列を参照）
    └─ レンダリング
    └─ HTMLテンプレートに埋め込み
    → RSPitem_{バージョン番号4桁}.html
※元々バラバラで処理していたものを無理やり1個のEXEにしてるので無駄は多いが、後から修正が楽なので内部はそのまま。

====================================================
6. スクリプトを修正した場合の注意点
====================================================

・.py ファイルを修正したら必ず再ビルドすること（EXEは自動更新されない）。

・HTMLテンプレート（アイテム表示用HTMLベース.html）を修正した場合も再ビルドが必要。
  テンプレート内の以下の行がデータ埋め込み位置:
    const rawData = ★★★★ここにデータを貼り付ける★★★★;
